# Especificação documental — NOW Mobile

Esta pasta reúne o pacote inicial de especificação do projeto **NOW Mobile**. Os arquivos de origem foram recebidos por handoff privado, verificados por tamanho e SHA-256 e descompactados sem conversão ou alteração de conteúdo.

## Organização

- `documents/`: documentos PDF e DOCX.
- `architecture/`: arquivo ZIP da arquitetura AWS, preservado como recebido. O ZIP aninhado não foi expandido nem reempacotado.
- `scenarios/`: cenários em Markdown.
- `media/images/`: imagens JPEG.
- `media/videos/`: vídeos MP4.
- `manifest.json`: inventário dos 64 arquivos originais, com caminho relativo ao diretório do projeto, tamanho em bytes e SHA-256.

O arquivo `now-specification-initial.zip`, mantido na raiz do projeto, é o pacote recebido e serve como referência de proveniência da extração.

## Escopo desta fase

Esta é uma fase **exclusivamente preparatória e documental**. Ela organiza, preserva e torna rastreáveis os materiais fornecidos. Nenhuma funcionalidade do aplicativo NOW Mobile foi implementada nesta etapa; a implementação fica para uma fase posterior, após os critérios e especificações serem revisados.

Os arquivos originais permanecem no formato e nos caminhos documentais definidos pelo pacote. `README.md`, `manifest.json` e o `TODO.md` da raiz são artefatos de organização e rastreabilidade criados durante esta preparação, não substitutos dos materiais originais.
